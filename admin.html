座位表管理

這一頁只給新人使用，請不要分享給賓客。所有處理都在你的瀏覽器內完成，Excel 不會被上傳到任何地方。

一、更新座位表

  1. 選擇最新的「喜宴座位表」Excel 檔（.xlsx）。
  2. （選用）選擇「桌卡位卡生成器」匯出的位卡名單備份，位卡名稱會自動帶入。
  3. 檢查下方轉換結果：家人桌、同行、兒童座椅、位卡名稱都可以手改。
  4. 按「下載 seats.js」，再把它上傳到網站覆蓋舊檔（GitHub：Add file → Upload files → Commit changes）。
