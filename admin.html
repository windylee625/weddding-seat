座位表管理

這一頁只給新人使用，請不要分享給賓客。所有處理都在你的瀏覽器內完成，Excel 不會被上傳到任何地方。

一、更新座位表

  1. 打開這頁時會自動載入網站目前的名單。座位表 Excel 有更新時，再選擇新的 Excel；只想改同行或顯示名稱，就不用選。
  2. 在下方名單修改：
    同行：勾選要一起的人（可以跨桌），按上方「設為同行」；要拆開就勾選後按「解除同行」。同一組會用同一個底色。
    顯示名稱：賓客查詢時看到的名字，也是飯店位卡擺放圖上的名字。
    家人桌：勾選後該桌不指定座位，賓客只看到桌號，飯店不放位卡。
  3. 按「下載 seats.js」，確認下載的檔名是 seats.js（不是 seats (2).js），再上傳到 GitHub 覆蓋舊檔。
